# Ledgerline

Store for the Ledgerline trading journal.

## Develop
```
pnpm install
pnpm exec vite dev
```

## Build
`pnpm exec vite build` writes a single-file site to `dist/`. The 3D journal viewer ships at `/3d.html`.

## Publish
See [DEPLOY.md](DEPLOY.md). GitHub Pages and the custom domain are not switched on yet.

Checkout runs in Stripe test mode: no card details are collected and nothing is charged.
